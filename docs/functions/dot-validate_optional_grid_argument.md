# Validate a coordinate endpoint argument

```r
.validate_optional_grid_argument(value, n, name, lines_name)
```

## Arguments

- `value`: Argument value, or `NULL`.
- `n`: Expected argument length.
- `name`: Argument name used in error messages.
- `lines_name`: Name of the associated line-index argument.

## Returns

The validated argument, or `NULL`.

## Description

Validate a coordinate endpoint argument
