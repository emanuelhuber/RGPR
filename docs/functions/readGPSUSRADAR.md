# Read US Radar GPS coordinate files

```r
readGPSUSRADAR(dsn, toUTM = FALSE)
```

## Arguments

- `dsn`: Character string specifying the path to the GPS file.
- `toUTM`: Logical. If `TRUE`, coordinates are converted from geographic coordinates (EPSG:4326) to UTM coordinates using `lonLatToUTM`. Default is `FALSE`.

## Returns

A list containing:

- **mrk**: Data frame with columns: `x`, `y`, `z`, and `id`.
- **crs**: Character string describing the coordinate reference system. Returns `"EPSG:4326"` when `toUTM = FALSE`; otherwise returns the UTM CRS generated by `lonLatToUTM`.

## Description

Reads a GPS coordinate file exported by US Radar systems and returns profile coordinates together with the associated coordinate reference system (CRS).

## Details

The input file is assumed to contain comma-separated values with longitude, latitude, elevation, and trace or marker identifiers. Coordinates can optionally be converted from geographic coordinates (WGS84) to UTM coordinates.

The function assumes that the input coordinates are stored as longitude/latitude values in the WGS84 geographic coordinate system (EPSG:4326). When `toUTM = TRUE`, the coordinates are projected to the appropriate UTM zone and returned in metres.

The returned object can be used to georeference a `GPR` profile.

## Examples

```r
## Not run:

gps <- readGPSUSRADAR("profile.csv")

head(gps$mrk)
gps$crs

gps_utm <- readGPSUSRADAR("profile.csv", toUTM = TRUE)
gps_utm$crs
## End(Not run)
```
