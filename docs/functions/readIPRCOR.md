# Read IDS GeoRadar COR GPS files

```r
readIPRCOR(dsn, toUTM = FALSE)
```

## Arguments

- `dsn`: Character string or connection pointing to a COR file.
- `toUTM`: Logical. If `TRUE`, geographic coordinates are converted from WGS84 (EPSG:4326) to UTM coordinates using `lonLatToUTM`. Default is `FALSE`.

## Returns

A list containing:

- **mrk**: Data frame with columns: `x`, `y`, `z`, `id`, `date`, and `time`.
- **crs**: Character string specifying the coordinate reference system. Returns `"EPSG:4326"` when `toUTM = FALSE`; otherwise returns the UTM CRS generated by `lonLatToUTM`.

## Description

Reads a COR file generated by IDS GeoRadar systems and extracts GPS coordinates, elevations, timestamps, and trace identifiers associated with a GPR profile.

## Details

The input coordinates are assumed to be geographic coordinates (latitude/longitude, WGS84). Coordinates can optionally be projected to the corresponding UTM coordinate system.

COR files contain GPS positions associated with radar traces in the following format:

```
trace date time north N/S east E/W elevation unit quality
```

Coordinates located in the southern hemisphere (`S`) or western hemisphere (`W`) are automatically assigned negative values before optional projection to UTM coordinates.

The returned coordinates can be used to georeference a `GPR` object.

## Examples

```r
## Not run:

gps <- readIPRCOR("PROFILE.COR")

head(gps$mrk)
gps$crs

gps_utm <- readIPRCOR("PROFILE.COR", toUTM = TRUE)
gps_utm$crs
## End(Not run)
```
